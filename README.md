# Etch-a-Sketch

A browser sketchpad built for [The Odin Project](https://www.theodinproject.com/lessons/foundations-etch-a-sketch) Foundations course.

## How to use

1. Open `index.html` in your browser.
2. Move your mouse over the grid to draw.
3. Each pass over a square gives it a random color and makes it 10% darker. Ten passes make it fully colored.
4. Click **New grid** and enter a number from 1 to 100 to start a fresh sketch pad with that many squares per side.

## What I practiced

- Creating elements with JavaScript (`createElement`, `appendChild`)
- Flexbox with `flex-wrap` to lay out a grid
- Mouse events (`mouseover`)
- `prompt` input and validation
- Random RGB colors and the CSS `opacity` property
